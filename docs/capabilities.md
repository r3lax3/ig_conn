# Возможности канала Instagram

Что канал `individual_instagram_account` умеет сейчас, чего пока нет и чего не будет, потому
что этого не умеет Instagram или библиотека aiograpi 2.0.15. Состояние на этап 1: код
реализует контракт 2.1 (что из 2.2 не перенесено, в [README](../README.md#контракт-22-что-ещё-не-перенесено)).

## Ответ на §10 контракта

Формат сообщения о возможностях контрактом не задан, поэтому значения ниже — по полям §10.

```json
{
  "connect_method": "pairing_code",
  "can_edit": false,
  "can_delete": false,
  "can_pin": false,
  "delivery_receipts": false,
  "read_receipts": false,
  "supports_buttons": false,
  "supports_groups": false,
  "formatting": [],
  "max_text_length": null,
  "max_file_bytes": null,
  "max_attachments": 0,
  "recipient_kinds": ["username", "external_id"]
}
```

| Поле | Значение | Почему |
|---|---|---|
| `connect_method` | `pairing_code` | В 2.1 вход Instagram выражается только так: `connect.start` с `login`, затем один `connect.confirm` с `password` и `totp_secret` (наше расширение 2.1). QR для входа в личный аккаунт со стороннего клиента Instagram не даёт. По 2.2 это будет `connect_methods: ["login_password", "session"]`, когда вход челленджами и импорт Сессии будут перенесены |
| `can_edit` | `false` | В aiograpi 2.0.15 нет метода правки сообщения Direct. `command.edit` → `edit_unsupported` |
| `can_delete` | `false` | Instagram умеет отзывать сообщения, в aiograpi есть `direct_message_unsend`, но в этапе 1 не реализовано. `command.delete` → `channel_rejected` |
| `can_pin` | `false` | Закрепления сообщений Direct в aiograpi нет, опрос инбокса его не показывает. `event.message_pinned` не шлём |
| `delivery_receipts` | `false` | Instagram не сообщает доставку сообщения Direct; `delivered` в `result` не заполняется |
| `read_receipts` | `false` | Instagram отдаёт отметку «просмотрено» по треду, но коннектор её пока не публикует. Без неё `event.read_receipt` не шлём: не выдумываем |
| `supports_buttons` | `false` | Кнопок в Direct личного аккаунта нет |
| `supports_groups` | `false` | Групповые треды пропускаются и во входящих, и в отправке (этап 1: только личные диалоги) |
| `formatting` | `[]` | Текст Direct не поддерживает разметку; спаны `format` игнорируются, текст уходит как есть |
| `max_text_length` | не объявляем | Ни Instagram для private API, ни aiograpi лимит не документируют. Официальный Instagram Messaging API (для бизнес-аккаунтов, не наш путь) ограничивает текст 1000 символами; для личного аккаунта через private API число не проверено. Коннектор текст не режет: если Instagram откажет (4xx), ответ будет `channel_rejected` |
| `max_file_bytes`, `max_attachments` | нет / `0` | Вложений в этапе 1 нет: `command.send` с `attachments` → `channel_rejected` |
| `recipient_kinds` | `username`, `external_id` | Поиск по username и по Instagram ID. По телефону личный аккаунт людей не ищет: `phone` → `recipient_not_found` |

`event.capabilities` (2.2) не нужен: Instagram не даёт отдельных ограничений по аккаунту,
которые отличались бы от канальных.

## Матрица

Состояния: **работает** — сделано и проверено тестами (против живого Instagram ещё не
прогонялось, см. README); **ещё нет** — Instagram и aiograpi это позволяют, не сделано в
этапе 1; **не умеет Instagram** / **не умеет aiograpi** — причина вне коннектора;
**вне контракта** — контракт это исключает.

### Вход и Сессия

| Возможность | Состояние | Как / почему |
|---|---|---|
| Вход по логину, паролю и TOTP-секрету | работает | Веб-вход в безголовом Chromium через прокси Аккаунта, `sessionid` → aiograpi `login_by_sessionid`. Коды 2FA коннектор генерирует сам |
| Вход без 2FA | работает | `connect.confirm` без `totp_secret` |
| Вход через private API (aiograpi `login`) | не используется | На проверке Instagram отвечал 429 на вход через private API даже отдохнувшему аккаунту с прежним устройством, браузерный вход при этом проходил |
| Переподключение с прежним Устройством | работает | Профиль браузера и настройки aiograpi создаются один раз и хранятся зашифрованными: новое устройство на каждый вход провоцирует проверки |
| Сессия переживает рестарт | работает | Сессия из базы поднимается без входа и проверяется одним запросом |
| Проверки при входе: код из SMS или почты, подтверждение в приложении, чекпоинт | ещё нет | Нужен вход челленджами (2.2), когда оператор отвечает на каждый шаг. Сейчас `connect_failed` с подсказкой пройти проверку в приложении и повторить |
| Капча при входе | ещё нет | Тоже челлендж 2.2; решать капчу сам коннектор не будет |
| 2FA кодом из SMS | ещё нет | Челлендж `code` (2.2). Сейчас поддержана только 2FA через приложение-аутентификатор |
| Вход по QR | не умеет Instagram | Для входа в личный аккаунт стороннего клиента QR нет |
| Импорт готовой Сессии | ещё нет | `method: session` (2.2) |
| Выход и закрытие Сессии по команде | ещё нет | `command.disconnect` (2.2). Выход есть только для Сессии, которую коннектор сам отклонил (Аккаунт занят другим Источником) |
| Вход через SOCKS5-прокси с логином и паролем | не умеет Chromium | Chromium не поддерживает SOCKS5 с авторизацией; нужен HTTP(S)-прокси. Уже подключённые Аккаунты через такой прокси работают |

### Отправка

| Возможность | Состояние | Как / почему |
|---|---|---|
| Текст в существующий личный диалог | работает | Один запрос, без повторов; метка `client_context`; при неясном исходе сверка с историей диалога, иначе `send_unconfirmed` |
| Первое сообщение человеку без диалога | ещё нет | aiograpi умеет (`direct_send` по `user_ids`), но свежеподключённый аккаунт, пишущий первым, рискует ограничением. Сейчас `channel_rejected` «starting new dialogs is stage 3» |
| Ответ с цитатой (`reply_to_external_id`) | ещё нет | Цитате нужна метка цитируемого сообщения. Сейчас текст уходит без цитаты |
| Фото, видео | ещё нет | aiograpi умеет (`direct_send_photo`, `direct_send_video`), этап 2 вместе с S3 |
| Файлы (документы) | ещё нет | aiograpi `direct_send_file` есть; Instagram не принимает PDF, DOCX и архивы, набор типов уточнять живьём |
| Голосовые | вне контракта | Контракт 2.1 голосовые исключает; aiograpi `direct_send_voice` есть |
| Правка отправленного | не умеет aiograpi | Метода нет; `edit_unsupported` |
| Отзыв отправленного | ещё нет | aiograpi `direct_message_unsend`; сейчас `channel_rejected` |
| Реакции | ещё нет | aiograpi `direct_send_reaction`; команды реакций появились в 2.2 |
| Форматирование текста | не умеет Instagram | В Direct нет разметки |
| Кнопки | не умеет Instagram | В Direct личного аккаунта нет |
| Группы | ещё нет | aiograpi читает и пишет в групповые треды; в этапе 1 только личные диалоги |
| Статус доставки | не умеет Instagram | Instagram не сообщает доставку |

### Входящие

| Возможность | Состояние | Как / почему |
|---|---|---|
| Тексты и ссылки личных диалогов | работает | Опрос основного инбокса раз в `INBOUND_POLL_INTERVAL`, время сообщения из Instagram, без дублей и потерь при рестарте |
| Без отметки «прочитано» | работает | Опрос читает с `visual_message_return_type=unseen` и ничего не отмечает: от опроса у собеседника «просмотрено» не появляется |
| Мгновенная доставка (realtime) | ещё нет | В aiograpi есть клиент Realtime MQTT; сейчас опрос по HTTP, задержка до интервала опроса |
| Фото, видео, голосовые, пересылки, истории | ещё нет | Приходят как `kind: unsupported` с пустым текстом, чтобы оператор видел, что клиент что-то прислал. Загрузка в S3 — этап 2 |
| Запросы на переписку (pending) | ещё нет | Пропускаются: принять запрос — отдельное действие (этап 2). Сообщение придёт, когда диалог окажется в основном инбоксе |
| Групповые чаты | ещё нет | Пропускаются |
| Свои сообщения Аккаунта из приложения | ещё нет | Не публикуются. По 2.2 это `direction: outbound` |
| История до подключения | ещё нет | Сознательно не загружается: CRM получает только сообщения после подключения |
| Отметка прочтения собеседником (`event.read_receipt`) | ещё нет | Instagram отдаёт «просмотрено» по треду; не публикуется |
| Удаление сообщения собеседником (`event.message_deleted`) | ещё нет | Опрос удалений не видит: сообщение просто пропадает из треда. Без факта от Instagram не шлём |
| Закрепление (`event.message_pinned`) | не умеет aiograpi | Нет в API библиотеки |
| «Печатает» | ещё нет | Только через Realtime |

|---|---|---|
| `active`, `needs_reconnect` + `deauthorized`, `error` + `peer_flood` / `source_offline`, `disabled` | работает | Только по ответу Instagram, только при смене, включая возврат в `active` |

| Несколько процессов на канал | ещё нет | Сессия живёт в памяти одного процесса; один экземпляр на канал |
